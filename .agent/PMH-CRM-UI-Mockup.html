Re-organized into 4 functional buckets. Permissions are matrix-based: Property Type × Module × Action.
Settings re-grouping rationale: the current Settings module mixes everything in a flat tab strip — unmanageable when Commercial (Mall/Office/Retail/Shophouse) is added. We propose 6 clear buckets:
1. Users — User accounts, login, profile
2. Roles — Role library organized per property type (sub-tabs Residential / Mall / Office / Retail / Shophouse), each role lists assigned team members
3. Projects — Central project management — every project's team access (who can see/edit) is configured here
4. Master Data — Picklists scoped per property type (Mall categories ≠ Office categories)
5. Templates — Bilingual Offer Letter / Lease Agreement variants per asset class
6. System — FX, VAT, Email, Numbering, Workflow approvals
